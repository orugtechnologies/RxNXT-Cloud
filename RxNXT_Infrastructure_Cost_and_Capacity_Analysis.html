Production: $20/month (~₹1,680). Unlocks multi-schedule cron triggers (8:00 AM, 1:30 PM, 8:30 PM IST) and 300s function execution duration.

Role: Relational multi-tenant clinical data store with Prisma ORM and Supavisor connection pooling.

Pilot: ₹0 on Free tier (500 MB holds ~150,000 complete prescription records).

Production: $25/month (~₹2,100) for 8 GB auto-scaling disk (3.5M+ prescriptions), point-in-time recovery (PITR), and automated daily backups.

💬 3. Meta WhatsApp Cloud API

Role: Official Graph API v20.0 delivery of prescription PDFs, smart dose reminders, and chronic refills.

Pricing: Billed at Meta's native base utility template rate in India (~₹0.12 to ₹0.14 per message). 1,000 service conversations are free every month.

Advantage: Eliminates third-party markups (Twilio / Gupshup), saving ₹0.50+ per message.

📄 4. Client-Side PDF Generation (jsPDF)

Role: Generates branded A4 prescription PDFs with doctor digital signatures and clinic logos.

Cost: ₹0 Server Overhead.

Why: PDFs are compiled inside the doctor's web browser DOM. 1,000 doctors downloading PDFs at the same second causes 0% server CPU strain.

4. Why RxNXT Operates at Substantially Lower Costs Architecture Highlights
1. Direct Meta Graph API vs. Twilio / Intermediaries: Third-party providers charge between ₹0.60 and ₹0.85 per WhatsApp message. Connecting directly to Meta Cloud API drops message costs to ~₹0.13. Across 20 busy clinics sending 20,000 reminders/month, this single design choice saves ~₹10,000 to ₹14,000 in monthly operating expense.
2. Eliminating Server-Side Headless Browsers: Conventional EMRs render PDFs on the server using headless Chrome/Puppeteer, requiring expensive compute instances ($40–$100/mo). RxNXT generates PDFs directly in the browser DOM via jsPDF, entirely eliminating this compute footprint.
3. Atomic PostgreSQL Queue Locking: The reminder cron uses PostgreSQL's native FOR UPDATE SKIP LOCKED mechanism. This guarantees zero duplicate messages and instant execution without requiring expensive enterprise message queue clusters during the initial 50 clinics.
